# WiFi Send

Android-приложение для планшета: превращает его в «флешку по Wi‑Fi».

- С любого телефона (iPhone, Android) в той же Wi‑Fi сети открываешь в браузере адрес планшета.
- Главный экран: **📤 Отправить** и **📂 Просмотреть**.
- Файлы хранятся в папке **WiFiSend** на планшете. Если планшет подключён к компьютеру кабелем
  (режим «Передача файлов»), эта же папка видна на компьютере — после загрузки обнови папку (F5).
- Уведомление на планшете о каждом полученном файле.
- Тёмная/светлая тема, русский/английский.

## Установка

1. Открой на планшете страницу **Releases** этого репозитория:
   https://github.com/Alex2210422/WiFi_Send/releases/latest
2. Скачай **WiFiSend.apk** и открой его. Разреши установку из этого источника, если Android спросит.
3. Открой **WiFi Send** → «Разрешить доступ к файлам» → включи переключатель.
4. «Не усыплять приложение» → разрешить (чтобы сервер не выключался при погасшем экране).
5. «Запустить» — появится адрес вида `http://192.168.x.x:8080`. Открой его на телефоне.

## Сборка

Собирается автоматически через GitHub Actions при каждом изменении в ветке `main`.
